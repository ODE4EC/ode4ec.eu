# Work plan

The work starts and ends with real use cases: partners set the requirements, the tool work answers them, and the same use cases evaluate the results.

<WorkFlow>
  <FlowStep title="Use cases">Industrial use cases that set the requirements and evaluate the results.</FlowStep>
  <FlowStep title="Design entry and flows">Modular frameworks, standardised interfaces and open data exchange formats.</FlowStep>
  <FlowStep title="Verification">Industry-standard verification with formal, UVM-inspired and Python-based environments.</FlowStep>
  <FlowStep title="AI-driven methods">New AI-driven methodologies for hardware design.</FlowStep>
  <FlowStep title="Ecosystem">Dissemination, exploitation and the long-term sustainability of the results.</FlowStep>
</WorkFlow>
