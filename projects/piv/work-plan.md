# Work plan

Three technical work packages build the tools: design entry and flow integration, verification, and AI-driven design. A use-case work package measures them against real designs from the consortium, and two more share the results and keep the project running.

<WorkFlow>
  <FlowStep title="Use cases">Partners' real designs set a baseline with today's open source tools, then measure every snapshot of the new ones against it.</FlowStep>
  <FlowStep title="Design entry and flows">High-level hardware languages such as Chisel and Spade, CIRCT and MLIR, and tool flows that run in CI/CD pipelines.</FlowStep>
  <FlowStep title="Verification">Verification on par with industry practice: Python-based and UVM-inspired environments, cross-domain and formal verification.</FlowStep>
  <FlowStep title="AI-driven design">AI assistance from high-level modelling to RTL, and AI-guided design space exploration for RISC-V SoCs and accelerators.</FlowStep>
  <FlowStep title="Ecosystem">Documentation, training, onboarding into the Chips JU Design Platform, and a plan to keep the tools maintained after the project.</FlowStep>
</WorkFlow>

## Milestones

The technical work moves in three steps: a baseline of today's tools, then two public snapshots of the results, each followed by an evaluation on the use cases.

| When | Milestone |
|------|-----------|
| November 2026 | Baseline definition: roadmap and tools baseline |
| February 2027 | Work setup: use cases defined |
| November 2027 | First snapshot of the tools |
| May 2028 | Preliminary evaluation on the use cases |
| November 2028 | Second snapshot of the tools |
| May 2029 | Final evaluation and consolidation |
