# Technology

ODE4EC-PIV works on the seam between open source tools rather than on any single tool, so that what already exists becomes something a team can actually adopt. The work is organised around three concerns that reinforce each other.

## Productivity

Design entry, IP management and generator-based flows, along with the waveform and analysis tooling that engineers spend their days in.

## Interoperability

Modular frameworks, standardised interfaces and open data exchange formats that let heterogeneous tools hand work to each other without a custom script in between.

## Verification

Formal methods, UVM-inspired and Python-based environments, hardware and software co-simulation, and the continuous integration practice that keeps all of it honest as designs evolve.
