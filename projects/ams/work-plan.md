# Work plan

The work follows the path of a real design: better tools and automation, PDKs to design with, industrial designs that test everything in silicon, and training that helps new users adopt the flow.

<WorkFlow>
  <FlowStep title="Tools">Simulation, extraction and electromagnetic analysis for analogue and RF design.</FlowStep>
  <FlowStep title="Design automation">Generators, layout automation and sizing in the MOSAIC framework.</FlowStep>
  <FlowStep title="PDKs and silicon">PDKs that support the new tool features, and MPW runs to fabricate designs.</FlowStep>
  <FlowStep title="Industrial validation">Partners design real IP blocks with the open flow and measure them.</FlowStep>
  <FlowStep title="Training">Design examples, teaching material and tutorials for new users.</FlowStep>
</WorkFlow>
